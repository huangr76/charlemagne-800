# 穿越公元800年 · 查理曼帝国实录

面向课堂的四站历史互动小游戏，依据陈思琦《法兰克王国与西欧封建制度》穿越者版教学设计（修订2）制作。

## 在线体验

https://huangr76.github.io/charlemagne-800/

- 四站：王室档案库、加冕教堂、贵族封地、王室庄园。
- 包含配对、排序、12道选择题与9道文字思考题。
- 提交后展开参考答案和思考过程；支持自动保存与见闻录导出。
- 作答只保存在学生使用的浏览器中，不会提交到本仓库或教师端。

## 本轮教学调整

史料文字和出处按原教学设计照录；时间线排序不显示年份；补充制度的积极作用；第四站新增劳动人民生产实践的论证题。

## 图像与材料

- 查理曼肖像：Albrecht Dürer，1511—1513年。
- 查理曼加冕：Friedrich Kaulbach，1861年。
- 臣服礼图像：克莱蒙地区14世纪场景的17世纪摹本，法国国家图书馆藏。
- 以上历史图像来自 Wikimedia Commons 的公有领域数字复制图，具体链接见游戏中的“图像与材料说明”。
- 档案库与庄园图片为AI场景复原，仅用于情境体验，不作为历史证据。
- 后世史料和制度概括在游戏中标明时间与使用范围。
